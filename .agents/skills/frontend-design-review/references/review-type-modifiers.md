# Review Type Modifiers

## PR review
Focus on implementation, design tokens, component reuse, states, accessibility, and regressions.

## Creative design review
Focus on conceptual direction, typography, visual distinctiveness, composition, and coherent motion.

## Product design review
Focus on task flow, action hierarchy, navigation, progressive disclosure, and recovery.

## Accessibility audit
Check keyboard navigation, visible focus, semantics, contrast, zoom/scaling, and screen-reader behavior.

## Design-system audit
Check tokens, component variants, spacing, typography, colors, and documented exceptions.
