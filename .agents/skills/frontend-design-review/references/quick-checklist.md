# Quick Checklist

- [ ] Primary user task is obvious.
- [ ] One clear primary action per view where appropriate.
- [ ] Existing design-system components are reused.
- [ ] Semantic tokens replace hardcoded visual values.
- [ ] Default/loading/empty/error/offline/disabled/focus states exist where relevant.
- [ ] Keyboard navigation works.
- [ ] Visible focus is present.
- [ ] Contrast and non-color cues are sufficient.
- [ ] Layout adapts without clipping at target sizes/scales.
- [ ] Error messages explain a useful next action.
- [ ] Runtime screenshots/inspection were performed, not only static code review.
